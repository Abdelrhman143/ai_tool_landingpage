# AI SEO Platform Landing Page

Act as a Senior Product Designer, Senior Frontend Developer, and Creative Director.

Create a premium SaaS landing page for an AI-powered SEO platform targeting Arabic-speaking businesses, e-commerce stores, and website owners.

## About The Product

The platform automatically crawls websites, detects SEO issues, generates AI-powered SEO improvements, allows users to review suggestions, and then applies approved changes directly to their CMS.

Key capabilities:

- Full website crawling
- SEO health scoring
- AI-generated Meta Titles
- AI-generated Meta Descriptions
- Schema generation
- FAQ generation
- Redirect suggestions
- Continuous monitoring
- 404 detection
- Historical reports
- WordPress, Shopify, Salla, Zid integrations

The overall feeling should communicate:

- Trust
- Automation
- Intelligence
- Performance
- Modern SaaS
- Arabic-first experience

# Section 3 — How It Works

Create a premium SaaS process section that clearly explains how the platform works in a simple and visual way.

The purpose of this section is to help visitors understand the workflow in less than 10 seconds.

## Section Layout

Centered section.

Large heading.

Short supporting description.

Below the heading, create a horizontal process flow on desktop.

Vertical process flow on mobile.

## Process Steps

### Step 01

**أضف موقعك**

قم بإضافة موقعك أو متجرك وربطه بالمنصة خلال دقائق.

### Step 02

**نفحص جميع الصفحات**

يقوم النظام بفحص الموقع واستخراج جميع إشارات ومشكلات SEO.

### Step 03

**اقتراحات بالذكاء الاصطناعي**

يقوم الذكاء الاصطناعي بإنشاء تحسينات للعنوان والوصف والمخططات والأسئلة الشائعة.

### Step 04

**راجع وطبّق التحسينات**

راجع الاقتراحات واعتمد ما يناسبك قبل تطبيقه مباشرة على موقعك.

## Visual Style

Modern SaaS timeline.

Use connected steps.

Use icons inside circular containers.

Use the primary color for active highlights.

Add subtle GSAP reveal animations.

Add line connectors between steps.

Use plenty of whitespace.

Avoid complex illustrations.

The workflow should feel simple, trustworthy, and effortless.

## Design Goal

Visitors should immediately understand:

- The platform is automated.
- The user remains in control.
- No SEO expertise is required.
- Improvements are applied with minimal effort.
- Review and approval of changes is a core product advantage.
